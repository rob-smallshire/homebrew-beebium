# Rob-smallshire Beebium

## How do I install these formulae?

`brew install rob-smallshire/beebium/<formula>`

Or `brew tap rob-smallshire/beebium` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rob-smallshire/beebium"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
